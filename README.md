# Marea Studio 🌊

Sitio web de **Marea Studio**, estudio de diseño web para negocios que necesitan una página nueva o renovar la que tienen.

Sitio estático (HTML + CSS + JS), sin dependencias ni paso de compilación.

## Editar

- **WhatsApp:** cambia `WHATSAPP` al inicio de `script.js` (formato `521` + 10 dígitos).
- **Textos:** todo está en `index.html`.
- **Colores:** variables al inicio de `styles.css`.

## Ver en local

Abre `index.html` en el navegador.

## Publicar en Vercel

1. En [vercel.com/new](https://vercel.com/new) importa este repositorio.
2. Framework Preset: **Other**. No hace falta comando de build.
3. Deploy. Cada `git push` a `main` vuelve a publicar solo.
